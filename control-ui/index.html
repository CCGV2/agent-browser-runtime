AGENT BROWSER

浏览器控制

由你决定 agent 可以使用哪些站点。

连接管理端

在运行浏览器的电脑上执行 node native-control-cli.cjs login，输入一次性登录码。远程访问请使用 SSH 隧道。

控制状态

暂停或修改名单会撤销所有临时授权；已经发出的动作无法撤回。

密码填写后的暂停会话

确认页面已不再显示敏感信息后，再恢复 agent。

    等待你的授权

    只授权你认识的站点。临时授权仅限该会话，30 分钟后到期。

    全局允许的站点

    适用于所有会话；空名单且没有临时授权时，不允许任何站点。填写协议、域名和必要的端口，不包含路径。

      临时授权

        首次配对

        安装官方 Playwright 扩展后，在扩展页面复制 Extension Token，粘贴一次即可。凭证只保存到本机，不会显示给 agent。保存后重新连接 MCP 才会使用新凭证。

        尚未配对时仍可使用官方交互式连接审批。这里的登录码与扩展凭证是两种不同的凭证。

        操作记录

        显示最近 200 条。记录站点和动作结果，不记录输入正文、页面内容或凭证。
